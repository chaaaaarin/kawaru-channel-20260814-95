# 🎁 「このニュース、動くべきか」5秒判断シート

AIニュースを見た瞬間に「様子見でいい」か「今すぐ確認すべき」かを振り分けるための早見シートです。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: ニュースを1件読んだら、まず「① 種別」を選び、その種別の判定項目をYES/NOで確認してください。

```text
【このニュース、動くべきか 5秒判断シート】

■ ステップ1：ニュースの種別を選ぶ
□ 新機能・性能アップ系（新モデル・新ツールの発表）
□ セキュリティ事件系（侵害・脱出・脆弱性の報道）
□ 資金調達・インフラ投資系（提携・出資・買収の発表）
□ 規制・ルール系（法律・ガイドライン・利用規約の変更）
□ 新製品・その他アップデート系（価格・UI・対応OSの変更）

■ ステップ2：新機能・性能アップ系を選んだ場合
□ 自社が既に使っているツールの新機能か
→ YES: 公式のリリースノートを開き、既存ワークフローへの影響を5分で確認する
□ 競合ツールの新機能か
→ YES: ベンチマーク数値だけメモし、乗り換え検討は月次の振り返りに回す（即断しない）

■ ステップ3：セキュリティ事件系を選んだ場合
□ 自社が該当ツール・該当OSSを利用しているか
→ YES: 開発チームに影響範囲の確認を即日依頼する
□ 利用していないが同種の仕組み（サンドボックス・外部連携）を使っているか
→ YES: 「自社の設定は同じ穴がないか」の確認を今週中のタスクに入れる
□ どちらでもない
→ YES: 知識として押さえておくだけでよい。緊急対応は不要

■ ステップ4：資金調達・インフラ投資系を選んだ場合
□ 取引先・仕入れ先に関係する企業の動きか
→ YES: 価格・供給への影響がないか、次回の定例で議題に上げる
□ 直接の取引関係がない
→ YES: 業界動向として記録するだけでよい

■ ステップ5：規制・ルール系を選んだ場合
□ 自社が対象地域・対象サービスに該当するか
→ YES: 法務・コンプライアンス担当に即共有する
□ 該当しない、または適用時期がまだ先
→ YES: カレンダーに施行日をメモし、通常業務に戻る

■ ステップ6：新製品・その他アップデート系を選んだ場合
□ 料金・利用条件が変わったか
→ YES: 契約中のプランへの影響を経理・総務に確認する
□ UIや対応環境が変わっただけ
→ YES: 対応不要。気づいた人が使うときに慣れればよい

指示例: 「このニュースの内容を貼るので、上記のシートに沿って種別と対応要否を判定して」とAIに貼って使うこともできます。
```

**ポイント**: 「今すぐ確認すべき」に振り分けたものだけ、担当者名と期限を添えてタスク化してください。
